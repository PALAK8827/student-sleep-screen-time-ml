Student Sleep, Screen Time and CGPA Prediction

Project Overview

This is a beginner-friendly Machine Learning project that explores the relationship between students' sleep habits, screen time, study hours, and CGPA.

Technologies Used

- Python
- Pandas and NumPy
- Matplotlib and Seaborn
- Scikit-learn

Model

Linear Regression

Evaluation

- Baseline MAE: 0.266
- Linear Regression MAE: 0.215
- Linear Regression R² Score: 0.312

Learning Outcomes

- Data cleaning and preprocessing
- Exploratory Data Analysis (EDA)
- Feature correlation analysis
- Model training and evaluation
- Cross-validation

Project File

"Untitled8.ipynb"

This project was created for learning and practicing basic Machine Learning concepts.
